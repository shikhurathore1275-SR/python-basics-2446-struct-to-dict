# Factorial Calculator in Python

## 1. Project Description
This project contains a Python program named `factorial.py` that calculates the factorial of a number.

The factorial of a non-negative integer is the product of all positive integers from 1 up to that number. The factorial of 0 is 1.

## 2. Features
- Calculates the factorial of a number.
- Demonstrates basic Python programming concepts.
- Beginner-friendly program.

## 3. Requirements
- Python 3.x
- A code editor or terminal to run the program.

## 4. Installation
1. Clone or download this repository.
2. Open the project folder.
3. Make sure Python 3 is installed on your computer.

## 5. Usage
Run the following command in your terminal:

```bash
python factorial.py
```

Follow the program's instructions to calculate a factorial, if prompted.

## 6. Example

For a factorial calculation with input `5`:

**Expected output:**
```text
Factorial of 5 is 120
```

Note: The exact output depends on the implementation in `factorial.py`.
